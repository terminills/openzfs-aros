# Source provenance

- Upstream project: https://github.com/openzfs/zfs
- Upstream release: OpenZFS 2.4.4
- Upstream base: `71a9f9578616a90c3c14bb59629fb4d31bfd68d1`
- AROS development snapshot: `08003887eb7abae778c4613b9c6257ce857b33c3`

This public repository starts with a clean source snapshot rather than importing
the development repository's internal coordination and test-artifact history.
The original source history remains separately retained. Local filesystem paths
in AROS helpers were normalized to example paths; contributor-facing documents
were added. Generated artifacts and internal coordination metadata are excluded.

All upstream licenses, copyright notices, and authorship files are retained.
Consult LICENSE, COPYRIGHT, AUTHORS, NOTICE and per-file headers. The bundled
upstream README describes upstream platforms, not the AROS port's support claims.
